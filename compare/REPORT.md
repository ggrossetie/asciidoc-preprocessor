# Comparison report: Asciidoctor vs. stream-clocked transducer

Generated by `npm run compare` — Asciidoctor.js 4.0.7, Asciidoctor (Ruby) 2.0.20.

Each case is converted (1) by Asciidoctor directly and (2) by the transducer, whose output is then converted by the *same* Asciidoctor (with no directive left to evaluate). "same" means the rendered text is identical. See COMPARISON.md for the analysis.

### A1

## Asciidoctor's reader without its parser

Drained on its own, Asciidoctor's `PreprocessorReader` turns `:flag: yes` + `ifdef::flag[FLAG-VISIBLE]` into:

```
[":flag: yes",""]
```

The transducer alone produces `[":flag: yes","","FLAG-VISIBLE"]`.
